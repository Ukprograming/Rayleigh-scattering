# レイリー散乱

`index.html` をブラウザーで開いて使います。通信・インストール・外部ライブラリーは不要です。`index.html`、`style.css`、`model.js`、`radiation-3d.js`、`app.js` を同じフォルダーに置いてください。

## 操作

1. **電荷の放射**：振動する負電荷から光が3D空間へ広がる様子を観察します。「振動の速さ」で振動数を0.5〜2.0倍（0.1刻み）に変更できます。振幅を固定しているため、1倍で放射強度1、2倍で16、0.5倍で0.0625です。画面の明るさ・数値・棒が連動します。「振動を止める」で源を止めても、放射済みの光は進みます。
2. **光による振動**：光の電場と逆向きに電子雲の濃い部分が偏る様子を観察します。原子核側の正電荷は雲の内部に固定し、輪郭のない濃淡で電子分布を表します。光を切ると原子核を中心とした対称な分布に戻ります。矢印は分子位置での入射電場の向きだけを示します。「光を切る」で入射光を止められます。
3. **波長と散乱**：赤650 nmを基準とし、比較する光を380〜750 nmで変更します。入射電場振幅・分極率・観測条件をそろえ、散乱強度を数値と棒で示します。

共通操作は「一時停止／再生」です。図をドラッグ（タッチでも可）するか、図にフォーカスして矢印キーを押すと3Dの向きが変わります。Homeキーで初期の向きに戻ります。振幅・全体の再生速度の設定、グラフ、長い解説文、重複する矢印は画面から除いています。OSで動きを減らす設定が有効な場合は一時停止状態で始まります。

## レイアウト

アプリ全体を `100dvh` のグリッドにし、見出し・切替・操作欄を除く領域を図に割り当てます。縦長画面での比較は上下、横長画面は左右です。低い画面ではタイトルと切替を同じ行にまとめます。はみ出しを隠して収める実装は使っていません。

## 物理モデル

- 分子サイズが波長より十分小さく、共鳴から離れ、分極率 α が一定の近似です。`p = αE`、`P ∝ p₀²f⁴`、`I(λ)/I(650) = (650/λ)⁴` を用います。450 nmは650 nmの約4.35倍です。
- 電子分布のずれは電場と逆向き、誘起双極子は電場と同じ向きで、入射光と同じ振動数で振動します。電子の軌道運動を描いているわけではありません。
- 双極子軸からの角度 θ に対する時間平均放射強度は `sin²θ`。代表する波面を、60°・90°・120°の3本の破線の輪で描きます。同時に描く組は最大2組です。細かな面や大量の光のサンプルは描きません。輪は全方向のうち一部を取り出した模式表示で、この3方向だけに放射するという意味ではありません。
- 十分な表示領域があるステップ1では、同じ距離の0°・45°・90°に観測マークと相対強度を表示します。初期設定でそれぞれ0・0.5・1、振動数2倍で0・8・16です。値は同じ距離にある初期設定の90°の強度を1とした時間平均値です。狭く低い画面ではマークを省略します。
- `radiation-3d.js` は破線の輪と粒子を同じ3D座標系で透視投影し、各線分と粒子を奥行き順に描きます。手前の破線は粒子の前、奥の破線は粒子の後ろを通ります。光の各点は全方向で同じ速さで放射状に進み、強度は過去の源の信号を参照します。振動数変更・停止の効果は外へ伝わります。輪は代表的な波面で、光が輪に沿って周回することを表しません。
- 源の信号の振幅は `f²`、時間平均放射パワーは `f⁴` です。破線の明るさには時間平均パワー・`sin²θ`・`1/r²` と固定露光 `1 - exp(-0.48 I)` を用います。見やすさのため端でフェードし、手前を太く、奥を細く薄く描きます。条件ごとに最大輝度をそろえる処理はしません。輪の間隔は混雑を避けるため一定とし、実際の波長や一周期ごとの波面の数は表しません。厳密な強度比は数値と棒で読みます。
- 波の曲線は電場のグラフで、媒質の変位ではありません。時間は大幅に減速し、分子サイズ・変位は拡大しています。波面の明るさは模式表示です。定量比較には数値と棒を使います。
- 初期表示と波長変更時は12秒分の信号履歴を用意するので、一時停止中でも放射が見えます。振動の速さの変更では履歴を保持します。
- 電源切替時の過渡応答、共鳴、分散、多重散乱、分子同士の干渉は扱いません。
- 観察順序は「放射 → 光による振動 → 波長比較」ですが、散乱の因果順は「光の電場 → 双極子の振動 → 放射」です。

参考：[Electric dipole radiation](https://farside.ph.utexas.edu/teaching/em/lectures/node95.html)、[Rayleigh Scattering](https://farside.ph.utexas.edu/teaching/jk1/lectures/node108.html)（Richard Fitzpatrick, University of Texas at Austin）。
